# Skills

Knowledge packages in the Agent Skills format: `<name>/SKILL.md` (procedure, checklists, rubrics) plus optional `references/` (question bank, templates, scales). Agents declare the skills they load. The same folders also work in Claude Code.

Planned skills: requirements-elicitation, requirements-analysis, game-domain, impact-analysis, agile-estimation, risk-management, business-value-roi, pm-artifacts, client-presentation, user-story-writing, jira-conventions, scrum-events.
