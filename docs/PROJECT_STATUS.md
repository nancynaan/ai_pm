## Costs to keep in mind

One feature through intake, discovery, analysis and assessment is about 7 Claude calls, 5–8 minutes and 150–230k subscription tokens; the whole pipeline to the backlog is 10–12 calls, 10–15 minutes and about 400k tokens. A replayed run (cassette) costs nothing.
