AI PM Pipeline: BPMN process models

Endless-runner project, Scrum. Drag to pan, Ctrl + scroll to zoom. The same files open in Camunda Modeler or demo.bpmn.io.

Download .bpmn

Lanes split each pipeline pool into the Pipeline engine (deterministic TypeScript: orchestration, validation, calculations, Jira/Confluence writes) and Agents (Claude calls that load skills and return schema-validated JSON). Thick-bordered boxes in the overview are call activities that point to the detailed diagrams.
